# TEMPLATE-UPGRADE：doc 元信息「当前状态 / 当前 Phase」改指针式默认值（doc meta pointer-style status）

## 1. 动机（去项目化）

模板 scaffold 为 `docs/00-scenario.md`、`docs/08-dev-plan.md`、`docs/09-verification.md` 的头部元信息表固定了「当前状态 / 当前 Phase」字段，且模板 doc-standards（00 §元信息行、08 §0 行、09 §0 行）对其只写了字段名、未约束写法。派生项目落地时的自然写法是把「当前阶段 + 演进史 + 各 Sprint/TC 收口摘要」整段重述进每个文件的头部单元格。

实证观察（某派生仓，Phase1 → Phase2D 共 7 个阶段演进）：「当前 Phase」这一横切事实同时整段存在于 00 §0 / 08 §0 / 09 §0 三处头部（外加 `ai/project-rules.md` §1 这一规范钦定的权威源）。某次阶段收口时只更新了 08/09 两处，00-scenario 头部滞留在三个 Phase 之前的「Phase2B 进行中」——**该漂移在 2026-07-30 至 08-07 间持续存在，无任何检查发现**，直到一次全量文档健康度复核（207 处路径失配甄别的伴生摸底）才暴露。同期还发现 8 处「已编码待合并 / 待执行」状态标记未随 PR 实际合并推进、1 处单元格误粘其他 Sprint 的超长验证内容。

根因不是某个维护者粗心，而是**结构性的**：

1. **多处重述无单一权威源约束**——横切事实（当前阶段）被 scaffold 固有形态复制到 ≥3 处头部，每处都是「看起来权威」的全文重述；
2. **状态变化需人工记忆同步点**——阶段收口时，AI / 维护者凭记忆改「想到的」两处，没有任何机制枚举全部重述点；
3. **doc-standards 对字段写法无约束**——只列字段名，整段重述与一句话指针都合规，漂移在规范层不可见。

对照：`ai/document-lifecycle-rules.md` §5 已有横切原则「横切事实必须有唯一权威源，其他文档引用权威源而非各自重述」，且 `ai/doc-standards/project-rules.md` §1 已明文「§1 是项目实例权威位置；Phase 变更必须传播回实例 §1」。**规范层已有权威源定义，缺的是把 00/08/09 元信息字段的默认写法从「重述」扭成「指针」**——本提案补的就是这一环。

## 1.1 与既有规则的关系（去重）

- **`ai/document-lifecycle-rules.md` §5（横切一致原则）**：已规定横切事实唯一权威源 + 引用不重述。本提案是它对「文档元信息字段」的**落地细化**——原则管「应该怎样」，本提案管 00/08/09 头部元信息这一高频漂移点的具体默认写法。层级不同（通用原则 vs 字段级默认值），指向不重复。
- **`ai/doc-standards/project-rules.md` §1（Phase 边界权威位置）**：已钦定 project-rules §1 为当前阶段权威源。本提案不改变权威源，只让 00/08/09 元信息默认指向它。对象不同（权威源本体 vs 权威源的引用侧写法），互补。
- **doc-standards 00 §元信息行既有措辞**（「当前状态」一句话状态即可，实现历史 / 演进叙事归 09 与 CHANGELOG，需要时留历史指针）：本提案把该措辞**升格并统一**到 00/08/09 三份 standard + scaffold，00 既有句是其子集。合并入。
- **#356 doc-overview-skeleton-alignment（已落地 v1.63.0）**：管引用式概述章的章节骨架；本提案管头部元信息表格单元格的写法。对象不同。
- **docs-health-review / §8.4 tidy 例外**：管漂移发生后的周期性清理；本提案管漂移的源头预防（写法默认值）。互补：预防 + 兜底。
- **check-template / CI 自检**：本提案**不引入**新的自检断言（元信息单元格的语义漂移无法机械化判断「哪份重述是对的」）；防漂移靠写法收敛，与模板仓「无自检门禁、避免过度治理」口径一致。

## 2. 拟改

### 2.1 doc-standards 三处字段措辞（核心）

`ai/doc-standards/00-scenario.md`、`08-dev-plan.md`、`09-verification.md` 的「文档元信息」字段行，统一补一句写法约束（示意措辞，落地时可微调）：

> 「当前状态 / 当前 Phase」为**一句话状态 + 权威源指针**（默认指向 `ai/project-rules.md` §1），不整段重述阶段演进史 / Sprint / TC 收口摘要；演进叙事归 `09` 验收记录与 CHANGELOG，需要历史时留指针。

### 2.2 scaffold 默认值

模板 scaffold 的 `docs/00/08/09` 元信息表默认值直接给指针式（如「当前状态：见 `ai/project-rules.md` §1」占位），派生项目初始化即是指针形态，不经历「先重述后矫正」。

### 2.3 状态标记收口纪律（伴生，轻量）

doc-standards 08 / 09 补一行：阶段 / Sprint / Wave 收口时，状态标记推进须 grep 全部重述点（如「待合并 / 进行中 / 待执行」）而非凭记忆改两处——把本次实证的 9 处滞后标记教训固化为收口检查项。不引入 CI 门禁。
